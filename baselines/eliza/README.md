# ELIZA baseline

Wade Brainerd's Python ELIZA (MIT licence, see `LICENSE`) with its DOCTOR script, from github.com/wadetb/eliza. It is
the implementation the 2025 three-party Turing test (Jones & Bergen) used as its ELIZA baseline, where ELIZA was judged
human 23% of the time.

It is here **only as a baseline to compare against**. Nothing in it is used by Helmus: no rule, no line and no word.
